# Kiểu neon — kế hoạch thực hiện

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** thêm luồng `--style neon`:
- Claude viết lời Việt thẳng từ brief;
- hình là sơ đồ neon do code xếp chỗ và kiểm, HyperFrames render ra `visuals.mp4`, ffmpeg ghép giọng, tiếng hiệu ứng và outro;
- luồng cũ vẫn chạy tới khi Tai chấp nhận.

**Architecture:**
- **Python giữ toàn bộ logic:**
  - đọc `scene.json` do agent viết, chỉ gồm tên phần tử, tên bố cục và số cụm;
  - tính tọa độ (PIL đo chữ);
  - kiểm chồng lấn, vùng an toàn, số màu, khoảng lặng hình và con số;
  - xuất `scene.resolved.json`: phần tử có tọa độ tuyệt đối và hành động có giờ.
- **`vshort/neon/kit.js` chỉ làm chuyển động:** đọc JSON đó, dựng DOM và một GSAP timeline dừng sẵn ở `window.__timelines["main"]`.
- **Render:** `vshort/hf.py` gọi CLI HyperFrames đã ghim; `render.render_neon` làm phần ffmpeg cuối.

**Tech Stack:** Python 3 (uv, pytest, PIL, numpy), ffmpeg, Node ≥ 22, `hyperframes@0.8.206`, `gsap@3.12.5`, icon Lucide (ISC),
font Be Vietnam Pro và IBM Plex Mono (OFL), Claude Code agents (`claude -p --agent`).

**Spec:** `docs/superpowers/specs/2026-11-09-kieu-neon-design.md`. Bản thử để đối chiếu: `docs/superpowers/specs/2026-11-09-kieu-neon-thu/template.html`.
Mọi chuyển động, màu và quầng sáng lấy theo composition `buildNeon` trong file đó.
